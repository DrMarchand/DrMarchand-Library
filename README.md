## Current identity boundary

The published operating-system identity is **DrMarchand’s OS™**. `Infinity OS` and `Infinite OS` are not current system names. The infinity symbol is architectural bridge language, not a replacement product name.

Private local production markers, private device identities, storage coordinates, credentials, and personal records do not belong in this public repository.
